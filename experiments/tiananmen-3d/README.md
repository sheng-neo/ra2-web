# 天安门三维交互模型

一个独立的 Three.js 实验页面，与游戏本体无关，用来验证浏览器端程序化三维建模与动画的能力。

**直接用浏览器打开 `index.html` 即可。** Three.js 及其官方扩展已打包进这一个文件（约 590 KB），
不依赖 CDN；只有界面字体从 Google Fonts 加载，离线时回退到系统字体。

## 内容

- **程序化建模**：城台与五阙券门（轮廓拉伸）、汉白玉须弥座与栏杆、面阔九间 × 进深五间的檐柱、
  菱花隔扇、和玺彩画额枋、斗拱层、重檐歇山顶（矩形逐圈放样：反宇曲线 + 翼角起翘 + 竖直山花）、
  正脊 / 鸱吻 / 戗脊 / 走兽、八盏宫灯、画像与标语、华表、石狮、外金水河与五座拱桥、长安街、国旗杆、松柏。
- **渲染**：物理天空（`Sky`）按时刻计算太阳方位与高度，并用天空生成环境贴图；琉璃瓦为程序生成的
  颜色图 + 法线图，按米平铺；金水河用 `Reflector` 做镜面倒影；夜景用 `UnrealBloomPass` 让宫灯与轮廓灯发光。
- **交互**：拖动旋转、滚轮 / 双指缩放、右键 / 双指平移（`OrbitControls`）；点击任意部件弹出说明与尺寸；
  六个机位预设（正面 / 广场 / 东侧 / 檐下 / 倒影 / 俯瞰）。
- **动画**：时刻滑杆与「延时一天」（48 秒走完 24 小时：日出、正午、黄昏、夜景连续过渡）、
  结构分层爆炸视图、飞行游览、自动旋转、国旗布料波动。
- 键盘：`1`–`6` 切换机位，`N` 昼夜切换，`L` 延时，`E` 分层，`T` 游览，`R` 自动旋转，`Esc` 关闭说明。

尺度按米近似真实比例（城台约 68 × 38 m，通高约 36 m）。画像位置以中性色板示意。

## 开发

```bash
cd experiments/tiananmen-3d
npm install        # three + esbuild
npm run build      # src/*.js → index.html（独立页面）与 artifact.html（页面片段）
```

- `src/lib.js` 材质、贴图、屋面放样等公共工具
- `src/gate.js` 城台、两翼与城楼
- `src/env.js` 周边环境、天空、灯光与时刻
- `src/main.js` 渲染器、后期、相机控制与交互
- `template.html` 页面样式与界面骨架，`/*BUNDLE*/` 处注入打包后的脚本
