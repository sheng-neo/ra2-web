# 天安门三维交互模型

一个独立的 Three.js 实验页面，与游戏本体无关，用来验证浏览器端程序化三维建模与动画的能力。

直接用浏览器打开 `index.html` 即可（Three.js 从 CDN 加载，需要联网）。

## 内容

- **程序化建模**：城台与五阙券门（轮廓拉伸）、汉白玉须弥座与栏杆、面阔九间 × 进深五间的檐柱、
  菱花隔扇、和玺彩画额枋、斗拱层、重檐歇山顶（矩形逐圈放样：反宇曲线 + 翼角起翘 + 竖直山花）、
  正脊 / 鸱吻 / 戗脊 / 走兽、八盏宫灯、画像与标语、华表、石狮、外金水河与五座拱桥、长安街、国旗杆、松柏。
- **交互**：拖动旋转、滚轮 / 双指缩放、右键 / 双指平移；点击任意部件弹出说明与尺寸；五个机位预设。
- **动画**：昼夜切换（泛光灯 + 轮廓灯 + 宫灯发光 + 星空）、结构分层爆炸视图、飞行游览、自动旋转、国旗布料波动。
- 键盘：`1`–`5` 切换机位，`N` 夜景，`E` 分层，`T` 游览，`R` 自动旋转，`Esc` 关闭说明。

尺度按米近似真实比例（城台约 68 × 38 m，通高约 36 m）。画像位置以中性色板示意。
