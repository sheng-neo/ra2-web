# 天安门三维交互模型

一个独立的 Three.js 实验页面，与游戏本体无关，用来验证浏览器端程序化三维建模与动画的能力。

**直接用浏览器打开 `index.html` 即可。** Three.js 及其官方扩展已打包进这一个文件（约 590 KB），
不依赖 CDN；只有界面字体从 Google Fonts 加载，离线时回退到系统字体。

## 内容

- **程序化建模**：城台与五阙券门（轮廓拉伸）、汉白玉须弥座与栏杆、面阔九间 × 进深五间的檐柱、
  菱花隔扇、和玺彩画额枋、斗拱层、重檐歇山顶（矩形逐圈放样：反宇曲线 + 翼角起翘 + 竖直山花）、
  正脊 / 鸱吻 / 戗脊 / 走兽、八盏宫灯、画像与标语、华表、石狮、外金水河与五座拱桥、长安街、国旗杆、松柏。
- **渲染**：物理天空（`Sky`）按时刻计算太阳方位与高度，并用天空生成环境贴图，另有程序噪声云层缓慢漂移；
  高画质下屋面铺约 2.7 万片实例化筒瓦（檐口带瓦当、滴水），斗拱为合并几何的真实斗、栱、昂构件，隔扇门为
  真实棂条几何；三级级联阴影（`CSM`）、地平线环境光遮蔽（`GTAOPass`）、4× 多重采样抗锯齿；金水河用
  `Water` 着色器（波纹法线来自 three.js 示例的 `waternormals.jpg`）做带日光高光的反射；夜景用
  `UnrealBloomPass` 让宫灯与轮廓灯发光。画质按钮可切换高 / 低（手机默认低，持续掉帧自动降级）。
- **细部与环境**：檐下实例化圆椽与飞椽，正脊脊筒与鸱吻，五阙券门的汉白玉券脸与九路门钉朱门（向内开启），
  石狮、盘龙华表、栏杆望柱头与栏板浮雕、须弥座线脚、城台北面马道；针叶簇松柏、示意游客人群、远景人民大会堂 /
  国家博物馆 / 人民英雄纪念碑；最后一道摄影感后期（暗角、颗粒、饱和度）。
- **交互**：拖动旋转、滚轮 / 双指缩放、右键 / 双指平移（`OrbitControls`）；点击任意部件弹出说明与尺寸；
  机位预设（正面为广场北缘人眼高度的经典照片机位 / 广场 / 东侧 / 檐下 / 倒影 / 俯瞰 / 键 `7` 高机位）；
  `H` 或「隐藏界面」得到无界面画面。
- **动画**：时刻滑杆与「延时一天」（48 秒走完 24 小时：日出、正午、黄昏、夜景连续过渡）、
  结构分层爆炸视图、飞行游览、自动旋转、国旗布料波动。
- 键盘：`1`–`6` 切换机位，`N` 昼夜切换，`L` 延时，`E` 分层，`T` 游览，`R` 自动旋转，`Esc` 关闭说明。

## 尺寸依据

模型按公开资料的真实尺寸建模（单位：米），主要数据及出处：

| 部件 | 尺寸 | 依据 |
|------|------|------|
| 通高 | 34.7（1970 年重建后，原 33.87） | 百度百科《天安门》、维基百科、北京旅游网 |
| 城台 | 下端 120 × 40，上端 116 × 38.76；总面积 4800 ㎡ | 百度百科《天安门》 |
| 城台高 | 汉白玉须弥座 1.59 + 朱红墩台 13 ≈ 14.6 | 百度百科、维基百科《北京城》 |
| 券门 | 中门 8.82 × 5.25；次间 7.6 × 4.43；梢间 6.2 × 3.83；门洞长 40 | 百度百科（中/英） |
| 城楼 | 面阔九间 57.14、进深五间 20.97；檐口约 62.77 × 27.25；台基连回廊 66 × 37；60 根柱，柱径 0.92 | 维基百科《天安门》、中新网、百度百科 |
| 画像 / 标语 | 画像 6 × 4.6（框 6.4 × 5）；标语各长 30、高 2.2 | 搜狐、维基百科、天安门地区管委会 |
| 外金水河 / 桥 | 河宽 18、长 500，北岸距墙基 32；桥长 23.15，御路桥宽 8.55、王公桥 5.78、品级桥 4.55 | 百度百科《金水河》《外金水桥》 |
| 华表 / 石狮 / 国旗杆 | 华表通高 9.57、柱径 0.98、同侧间距 96；石狮高 3.4；旗杆净高 30 | 天安门地区管委会、北京市政府网、百度百科 |
| 观礼台 | 大观礼台各长 95、宽 12；小观礼台各长 73 | 百度百科《天安门观礼台》 |

## 开发

```bash
cd experiments/tiananmen-3d
npm install        # three + esbuild
npm run build      # src/*.js → index.html（独立页面）与 artifact.html（页面片段）
```

- `src/lib.js` 材质、贴图、屋面放样等公共工具
- `src/gate.js` 城台、两翼与城楼
- `src/env.js` 周边环境、天空、灯光与时刻
- `src/main.js` 渲染器、后期、相机控制与交互
- `template.html` 页面样式与界面骨架，`/*BUNDLE*/` 处注入打包后的脚本
